What this mockup settles

No counts on chips. Matching the website: the label is the affordance, the number was noise.

The model picks the rows. Watch dad → brand, movement, band. Diamond rings → cut, metal, budget. Anniversary → kind of piece, stone. Mothers ring → nothing. Same index, four different shelves, one new field in the model's output.

Prose carries breadth, chips carry choice. The rule the voice follows: never name a chip's value in prose; name what lies beyond the chips ("pocket watches, watch bands", "thousands more").
