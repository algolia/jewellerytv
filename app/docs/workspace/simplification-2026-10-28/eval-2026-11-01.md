## The `searchable()` change did not land

Both attributes are still plain in `attributesForFaceting`:

```
Catalog_GemstoneAndPearlNavigationName
Catalog_JewelryMaterialNavigationName
```

and a direct facet query still fails:

```
Cannot search in `Catalog_GemstoneAndPearlNavigationName` attribute, you need
to add `searchable(Catalog_GemstoneAndPearlNavigationName)` to
attributesForFaceting.
```

The error stopped appearing in turns for a different reason: the agent no
longer calls `algolia_search_for_facet_values`. The search tool is now a
single `algolia_search_index` rather than one tool per index, and whatever
changed with it took the facet-search path with it. So the fix is still
outstanding — it just is not costing a step today.

`searchable()` is an **index** setting on `attributesForFaceting`, not a field
on the agent's facet list. The exact strings:

```
searchable(Catalog_GemstoneAndPearlNavigationName)
searchable(Catalog_JewelryMaterialNavigationName)
```

four words, where a week ago it was "A varied first look at opal jewelry."
